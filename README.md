# Network Toolkit

A Python-based networking utility built as a hands-on project for practicing Python, Linux, networking, and cybersecurity fundamentals.

## Features

- Display local hostname and network interface information
- Resolve domain names to IP addresses
- Ping hosts to test connectivity
- Scan TCP ports
- Choose custom port ranges from 1-65535
- Detect open TCP ports
- Measure scan completion time
- Save scan results as timestamped reports
- Handle invalid input and DNS resolution errors
- Interactive command-line menu

## Requirements

- Python 3
- Linux
- `ip` and `ping` utilities

This project was developed and tested on Linux Mint.
